## 拍摄设置与检查清单

1. 在 RPF-47 分支仓库根运行 `npm run dev -- --host 127.0.0.2 --port 4174 --strictPort`，只读页面打开 `127.0.0.2:4174`。此绑定仅限回环地址；`--strictPort` 避免 Vite 自动换端口。确认本演示未启动 `127.0.0.1:4185` 和 `127.0.0.1:8765` Lab 服务。
2. 使用桌面 1280×720；浏览器缩放 100%，切至中文。页面的来源状态、标题、计数、第二轮退款事实应清楚可读。
3. 从首屏开始录制，按时间表点击真实 `pge-event-14/15/16` 深链，再显示收据和历史 Witness。可以重载这些 GET 页面，但不可触发 POST、付费入口或任意新的 trial。
4. 英文补录只切换站点语言；事件 ID、hash、路线、来源和业务数据不能变化。键盘 Tab 能聚焦链接，Enter 能打开所选深链。
5. 收尾前检查视频时长 ≤180 秒、首尾完整、无黑屏/剪辑跳变/隐私信息；字幕/旁白不得使用“漏洞已发现”“因果已证明”“签名已认证”等超出证据的说法。

**当前素材状态：** 本环境确认没有安装的 ffmpeg/ffprobe/OBS 或可识别的桌面录屏工具；本次未安装依赖、未请求录屏权限、未产出视频。视频为 `UNAVAILABLE / NOT_RUN`，以上是可直接执行的真实拍摄脚本；需要实际视频时由用户在可用的本地录屏环境按此脚本录制并核对。
