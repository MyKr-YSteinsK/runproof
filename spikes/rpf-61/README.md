## 使用原则

最新[官方公告](https://openjiuwen.com/news/news-artical?id=248)更新于2026-10-20，创意截止改为 **2026-11-10**，桌面申报页显示同一日期；精确时刻/时区仍未知。内部保留10月30日提前准备目标。初赛先提交名称、简介、场景与技术方案，DEMO在创意通过后开发。门户公开要求 **ZIP、≤500MB**；本Plan只授权文本/PNG，未生成PPTX/ZIP或MP4。用户需按官方模板整理并打包，核对登录后的最终字段。

本轮 Provider/SDK/JVM/退款/业务POST/tokens/模型费用均为0；只重新校验公开历史证书。RPF-60 已用的一次额度不会重置。截图是当时运行画面的记录，见每图说明；截图上的LIVE是拍摄时状态，当前展示属于RECORDED。

RPF-60 仅 Explorer 为真实 DeepSeek；订单是确定性Target，配置是实际SDK中的scripted Fixture。RPF-57 独立会话才有真实Explorer与真实Target。两者不拼接成同一个实验。
